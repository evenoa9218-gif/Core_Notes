# units/ — 본문의 정본

2026-11-05부터 본문의 정본은 **여기**다. 노션이 아니다.
`data-*.js` 는 CI 가 이것으로 만드는 **읽기용 번들**이라 직접 고치면 다음 빌드에 덮인다.

```
units/{과목}/{단원id}.json   단원 하나 = 파일 하나
units/{과목}/_index.json     단원 순서 · 분류 목록 (번들 재조립에 필요)
```

## 단원 파일

```json
{"id":"민소001","t":"민사소송과 신의성실의 원칙","cat":"mp_1","lv":1,"tg":["★"],"b":[
 {"i":"1bavbkr","o":"<div class=\"cs-callout\">","b":[
  {"i":"qo5oea","o":"<div class=\"cs-h\">","h":"Ⅰ. 의의 및 적용범위","k":"2mgxmk"}
 ]}
]}
```

| 칸 | 뜻 |
|---|---|
| `i` | **블록 id. 영원히 안 바뀐다.** 진도·오답·메모·기출연결이 전부 여기 붙는다 |
| `o` | 여는 태그 그대로. 닫는 태그는 태그 이름으로 되만든다 |
| `b` | 자식 블록 (컨테이너일 때) |
| `h` | 속 HTML (줄일 때). 형광펜·O·X 같은 inline 마크는 HTML 그대로 둔다 |
| `k` | 전환 시점의 옛 줄 해시 — 예전 기록을 새 id 로 잇는 다리 |
| `w` | 블록 사이 공백 (전 과목 통틀어 12개) |

블록 하나가 한 줄이다. 줄 하나를 고치면 diff 도 한 줄이다.

## 규칙

- **`i` 를 바꾸거나 지우지 않는다.** 지울 때는 숨김(`"x":1`)을 쓴다.
  `tools/verify_ids.js` 가 직전 커밋 기준으로 막는다 — 이게 노션 시절 글자 수 불변식을 대신한다
- 컨테이너 안에 맨텍스트를 넣지 않는다. 공백은 `w` 블록으로
- 고친 뒤에는 `node tools/build_bundle.js && node tools/verify_units.js`

## 도구

| | |
|---|---|
| `tools/build_units.js` | 번들 → units (id 는 이미 있으면 되찾는다) |
| `tools/build_bundle.js` | units → 번들 |
| `tools/verify_units.js` | 왕복이 글자까지 같은가 |
| `tools/verify_ids.js` | 블록 id 가 사라지지 않았는가 |
