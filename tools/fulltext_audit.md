# 노션 원문 ↔ notion_raw md 전문대조 기록

verify_unit.py(md→HTML)와 audit_units.py(파일 정합성)로는 못 잡는 구간,
즉 **노션에서 옮겨적는 단계**를 단원별로 다시 받아 라인 단위 대조한 기록.

방법: notion-fetch 재수신 → <content> 블록을 md 파일 본문(헤더 주석 2줄 제외)과
순서대로 대조. props(과목·번호·주제·장·절·관·원본 p.·판례태그)도 대조.
